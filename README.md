## Descripción del Trabajo
Aplicación web desarrollada en un entorno JSP/Tomcat que resuelve un caso práctico de cotización y validación de datos[cite: 1, 2]. Integra de manera directa:
1. **Clase Math:** Aplicada para cálculos numéricos (raíces, potencias y redondeos).
2. **Clase String:** Aplicada para la validación, limpieza y transformación de cadenas ingresadas por el usuario.

---

## Instrucciones de Ejecución
1. Clonar este repositorio en tu máquina local.
2. Importar el proyecto en tu IDE favorito compatible con Java EE (Eclipse, NetBeans, etc).
3. Configurar y asociar un servidor **Apache Tomcat (v9/v10)**.
4. Ejecutar el archivo principal (`index.jsp`) seleccionando **Run on Server**.
